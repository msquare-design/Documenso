# M Square – Documenso Email Templates (Arabic / English)

Where to paste: when sending a document (or editing a Template) → step **Distribute / Settings** → **Email Options** → *Subject* and *Message*.

Variables Documenso fills in automatically:
- `{signer.name}` – recipient name
- `{signer.email}` – recipient email
- `{document.name}` – document title

---

## 1. General signing request / طلب توقيع عام

**Subject:**
```
Signature required: {document.name} | مطلوب توقيعكم: {document.name}
```

**Message:**
```
عزيزي/عزيزتي {signer.name}،

تحية طيبة وبعد،
نرجو التكرم بمراجعة المستند المرفق "{document.name}" وتوقيعه إلكترونياً عبر الزر أدناه.
في حال وجود أي استفسار، يسعدنا تواصلكم معنا بالرد على هذا البريد.

مع خالص التحية،
فريق إم سكوير

────────────────────

Dear {signer.name},

Please review and electronically sign the attached document "{document.name}" using the button below.
If you have any questions, simply reply to this email.

Kind regards,
M Square Team
```

## 2. Invoice / فاتورة

**Subject:**
```
Invoice for your signature: {document.name} | فاتورة بانتظار توقيعكم
```

**Message:**
```
عزيزي/عزيزتي {signer.name}،

نرفق لكم الفاتورة "{document.name}" للمراجعة والتوقيع بالاستلام.
نرجو التوقيع عبر الزر أدناه، وفي حال وجود أي ملاحظة على البنود أو المبالغ يرجى إبلاغنا.

شاكرين تعاونكم،
قسم الحسابات – إم سكوير

────────────────────

Dear {signer.name},

Please find attached invoice "{document.name}" for your review and acknowledgement.
Kindly sign using the button below, and let us know if you have any remarks on the items or amounts.

Thank you,
Accounts Department – M Square
```

## 3. Purchase order / أمر شراء

**Subject:**
```
Purchase Order approval: {document.name} | اعتماد أمر شراء
```

**Message:**
```
عزيزي/عزيزتي {signer.name}،

نرفق لكم أمر الشراء "{document.name}" للاعتماد والتوقيع.
نرجو التوقيع عبر الزر أدناه لنتمكن من المضي في إجراءات التوريد.

مع التحية،
قسم المشتريات – إم سكوير

────────────────────

Dear {signer.name},

Please find attached Purchase Order "{document.name}" for your approval and signature.
Kindly sign using the button below so we can proceed with the order.

Best regards,
Procurement Department – M Square
```

**Subject:**
```
Quotation for approval: {document.name} | عرض سعر للاعتماد
```

**Message:**
```
عزيزي/عزيزتي {signer.name}،

شكراً لاهتمامكم بخدمات إم سكوير.
نرفق لكم عرض السعر "{document.name}"، ونرجو توقيعه عبر الزر أدناه في حال الموافقة لنبدأ العمل.

مع التحية،
فريق المبيعات – إم سكوير

────────────────────

Dear {signer.name},

Thank you for your interest in M Square.
Please find attached quotation "{document.name}". If you approve, kindly sign using the button below and we will get started.

Best regards,
Sales Team – M Square
```

## 5. Contract / Agreement – عقد / اتفاقية

**Subject:**
```
Agreement for signature: {document.name} | اتفاقية بانتظار توقيعكم
```

**Message:**
```
عزيزي/عزيزتي {signer.name}،

نرفق لكم "{document.name}" للمراجعة والتوقيع.
نرجو قراءة البنود بعناية قبل التوقيع عبر الزر أدناه، وستصلكم نسخة موقعة من جميع الأطراف تلقائياً عند الاكتمال.

مع خالص التحية،
إم سكوير

────────────────────

Dear {signer.name},

Please find attached "{document.name}" for your review and signature.
Kindly read the terms carefully before signing using the button below. A copy signed by all parties will be emailed to you automatically once completed.

Kind regards,
M Square
```
